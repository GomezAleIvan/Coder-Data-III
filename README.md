# Coder-Data-III
Diplo Data III trabajo final

En este proyecto uso un dataset extraido de kaggle "gym.csv" que muestra distintas muestras de Genero, IBM, dietas, rutinas de ejercicio y objetivo. Intente utilizar BoW para vectorizar el texto pero se volvio una prediccion muy redundante por lo que opte solamente por Redes Neuronales para detectar patrones complejos se puede predecir segun el tipo de persona y el objetivo cual es el plan nutricional y de ejercicio que debe realizar la persona para lograrlo.
